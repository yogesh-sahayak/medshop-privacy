Medical Shop

Medical Shop is an offline billing app for a single medical shop. This page is its home page and privacy policy.

Privacy policy

All bills, patients, medicines, users and shop settings are stored only on the owner's phone.

If the owner turns on Google Drive backup, the app saves an encrypted copy of this data in a folder named "Medical Shop Backups" in the owner's own Google Drive. The backup is locked with a password that only the owner knows. It is never sent anywhere else.

The app asks only for the Google Drive permission that lets it see files it created itself. It does not read any other file in the Drive, does not share data with anyone, and does not use advertising or analytics.

To remove all data, delete the backups from Google Drive and uninstall the app.
